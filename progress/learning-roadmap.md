# Playwright Automation Masterclass — Learning Roadmap

## Goal
Become job-ready for Automation QA using **JavaScript + Playwright**, while building a professional GitHub portfolio.

## Learning Path

### Phase 1 — JavaScript Fundamentals
- Day 01: Variables, data types, console output
- Day 02: Operators and expressions
- Day 03: Conditions (if / else / switch)
- Day 04: Loops
- Day 05: Functions
- Day 06: Arrays
- Day 07: Objects
- Day 08: Array methods
- Day 09: Scope and error handling
- Day 10: Promises and async/await
- Day 11: Modules and reusable code
- Day 12: JavaScript QA practice project

### Phase 2 — Playwright Fundamentals
- Installation and project setup
- Browser, context, and page
- Locators and selectors
- Actions and assertions
- Forms and controls
- Test organization and configuration

### Phase 3 — Real-World Automation
- Login and registration flows
- Tables and pagination
- Tabs and windows
- Frames
- File upload/download
- Screenshots, video, tracing
- API testing

### Phase 4 — Framework Development
- Page Object Model
- Fixtures
- Reusable utilities
- Test data management
- Environment configuration
- HTML reporting

### Phase 5 — Advanced Automation & CI/CD
- Authentication and session reuse
- UI + API integration
- Parallel execution
- Debugging and Trace Viewer
- Git/GitHub workflow
- Jenkins / CI pipeline

### Phase 6 — Portfolio Projects & Interview Preparation
- End-to-end automation framework
- Real-world web application regression suite
- API + UI project
- Test strategy and framework documentation
- Automation QA interview preparation

## Progress Rule
A lesson is marked **Completed** only after Raj finishes the hands-on exercise and checkpoint for that lesson.
